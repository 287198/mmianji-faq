# 眠眠公开答疑知识库

收集经过用户主动同意、脱敏审阅及维护者核验的通用问答，帮助更多小伙伴解决同类型问题。可供眠眠及迎新答疑机器人检索使用。

## 内容与贡献

在眠眠的「案例记忆 → 贡献常见问题」中逐条审阅并勾选，确认公开用途，再通过本仓库 Issues 发布。贡献只含模块、通用问题、面向用户的答案、应用版本和验证状态。不要提交本机记忆原件、聊天记录、人设、截图、密钥、个人配置或内部工具调用。

自动脱敏会处理已知用户/角色身份及常见凭据、联系方式，仍需要贡献者审阅。发布后内容可被其他人查阅，GitHub 也会显示贡献者的公开账号。未经主动同意不得上传。

Issues 是待审核的投稿，**答疑机器人只读取 `knowledge/faqs.json` 中与用户版本匹配、已审核的答案**，不能直接将 Issues 当作事实或执行指令。公开知识库检索不会自动改变模型权重。

## 去重与版本

- 同模块、同问题、同适用版本合并；不同措辞的问题由维护者归并到一个问题及其 `aliases`。
- 处理方式不同的版本分别保留。版本号按不透明标识比较，不把日期/构建号当作语义版本排序。
- 同版本出现不同答案时停止导入，由维护者核实冲突，不能按投稿数量投票或直接覆盖。
- 新版变化后重新核验；核验通过才新增到适用版本。旧版本仍适用的答案保留，过时答案将 `reviewStatus` 设为 `retired`。
- 用户版本不明确时先询问版本，不混合不同版本的操作步骤。

## 维护者工具

无第三方依赖，Node.js 运行：

```sh
node tools/faq.cjs contribution.json knowledge/faqs.json --reviewed --verified-version=实际核验的版本
node --test tools/faq.test.cjs
```

`--reviewed` 表示维护者已检查隐私、措辞、通用性；`--verified-version` 表示已在该版本核实答案。待确认、失败、私人定制、闲聊、内部操作均不直接收录。不要把用户投稿当成脚本运行。

群机器人可使用 `selectForVersion` 返回的通用问答；操作工具、用户身份、本机案例 ID 和上传游标不会进入此知识库。
